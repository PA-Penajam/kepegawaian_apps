Karakteristik Full Retro:

  • Semua font bold/black — tidak ada font-normal atau font-medium
  • Semua teks uppercase — heading, button, badge, table header
  • Border-2 di semua elemen — button, badge, input, pagination
  • Shadow di semua interaktif — button, pagination, search
  • Kontras tinggi — sangat bold, sangat mencolok

Karakteristik Kombinasi:

  • Heading bold + uppercase — tapi deskripsi font-medium biasa
  • Table container retro — border-2 + shadow, tapi button/icon shadcn
  • Search input retro — border-2 + shadow
  • Button/Badge/Pagination shadcn — lebih halus, tidak terlalu mencolok
  • Balance — bold untuk struktur, clean untuk interaksi
