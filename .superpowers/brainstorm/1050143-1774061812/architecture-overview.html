Alur Login SSO (Step by Step)

1
User buka app-B — belum login
app-B detect tidak ada session → redirect ke kepegawaian-apps/login
2
User login di kepegawaian-apps
Fortify handle auth → generate session token (Sanctum)
3
app-B validasi token via API
Kirim token + HMAC signature → dapat info user + permissions untuk app-B
4
app-B cache hasil validasi (30-60 detik)
User bisa bergerak bebas tanpa round-trip tiap request
5
Logout — terpusat
kepegawaian-apps invalidate token → semua app otomatis logout saat cache expired
