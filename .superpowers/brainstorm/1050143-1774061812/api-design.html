Shortcut untuk middleware aplikasi lain
POST /api/v1/iam/logout Logout terpusat — invalidate token
{ "message": "Token invalidated" }
Semua app otomatis logout saat cache expired
WEB /sso/login?app=attendance&redirect=https://... Entry point SSO — halaman login terpusat
Setelah login berhasil → redirect ke ?redirect= dengan token di URL fragment atau cookie.
Aplikasi lain tangkap token → simpan di localStorage / cookie mereka sendiri.

Alur Integrasi di Sisi Aplikasi Lain

CONTOH MIDDLEWARE DI attendance-qr-system (Laravel)
function handle(Request $request, string $permission = null)
{
  // 1. Cek cache dulu
  $cached = Cache::get('iam_' . $token);
  if ($cached && !$permission) return $next($request);
  
  // 2. Kalau tidak ada, panggil IAM API
  $response = Http::withToken($token)
    ->withHeaders(['X-App-Key' => config('iam.api_key')])
    ->get('kepegawaian.local/api/v1/iam/validate');
  
  // 3. Cache 60 detik
  Cache::put('iam_' . $token, $response->json(), 60);
}

Security Layers pada Setiap Request

🔒
Layer 1 — Sanctum Token
Identifikasi user yang sedang login
🔑
Layer 2 — X-App-Key
Identifikasi aplikasi mana yang memanggil → permissions dikembalikan sesuai aplikasi itu
✍️
Layer 3 — HMAC-SHA256
Verifikasi request tidak dimanipulasi + anti-replay (5 menit window) — sudah ada di codebase

Endpoint Admin (Web — Hanya Super Admin)

GET /iam/applications → daftar aplikasi terdaftar
POST /iam/applications → daftarkan aplikasi baru + generate API key
GET /iam/applications/{id}/roles → kelola role per aplikasi
GET /iam/applications/{id}/permissions → kelola permission per aplikasi
GET /iam/users/{id}/roles → assign/revoke role user di semua aplikasi
